The Reality
04 / 07

Where It Broke

Figma mockups are easy. Real browsers gave me three big headaches.

✕ Problem 01
Severe Scroll Stutter
Adding 3D card tilt dropped scroll speeds below 30fps. It felt laggy and unpolished.
✕ Problem 02
Mobile Touch Conflict
The cursor particles got in the way of mobile thumb scrolling and drained battery.
✕ Problem 03
Name Wrapping
On small iPhone screens, "Chunamari" broke awkwardly onto a third line.
FAILURE ANALYSIS: SPOTTING BUGS BEFORE USERS DO ritvikchunamari.github.io
The Fixes
05 / 07

How I Fixed It

Simplifying the code made the design look and feel 10x better.

✓ Solution 01
Zero-Render Scroll
Removed 3D tilts and tied scroll to hardware frames. Locked in smooth 120fps.
✓ Solution 02
Touch Soft-Fade
Particles gracefully fade out on touch, leaving mobile gestures completely natural.
✓ Solution 03
Fluid Math
Used CSS clamp formulas so "Ritvik" and "Chunamari" fit edge-to-edge on any screen.
OUTCOME: BUTTERY SMOOTH 120FPS & EFFORTLESS RESPONSIVENESS ritvikchunamari.github.io
Takeaways
06 / 07

What I Learned

Two big lessons from building with code instead of just Figma.

LESSON 01
Performance IS Design.
A gorgeous effect is useless if it stutters. Fluidity and speed communicate quality faster than any visual graphic ever will.
LESSON 02
Restraint Over Noise.
It’s tempting to add every fancy animation. The best decision was deleting the 3D clutter so the actual work could stand out.
KEY INSIGHT: REAL CRAFT IS KNOWING WHAT TO REMOVE ritvikchunamari.github.io
