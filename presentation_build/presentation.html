03 • Technical Failures Post-Mortem
SLIDE 04 / 07

Where It Broke: The Reality of Browser Constraints

Designing in Figma is effortless; compiling into a high-performance browser runtime exposed critical edge-cases in animation budgeting, touch friction, and viewport geometry.

✕ Bottleneck 01 • Severe Scroll Stutter
3D RotateX & Continuous State Triggers
Attempted 3D perspective tilts on scroll cards. Continuous React state recalculations during scroll flooded the event loop, dropping frames to <30fps on high-DPI displays and causing visible stutter.
✕ Bottleneck 02 • Touch Device Cursor Clutter
Desktop Physics on Touchscreens
The kinetic cursor physics that felt snappy with a mouse became intrusive on mobile and tablet touchscreens, conflicting with native swipe inertia and eating up mobile battery/GPU cycles.
✕ Bottleneck 03 • Mobile Typography Overflow
Name Breaking & Awkward Wrapping
The name headline "CHUNAMARI" broke across lines or overflowed horizontally on narrower mobile screens (375px–390px), failing the editorial rule of keeping "Ritvik" on line 1 and "Chunamari" on line 2.
✕ Bottleneck 04 • The 3-Page Resume Spill
Awkward 6-Line Orphan Page
Initial resume PDF export bled into an awkward 3rd page containing only 6 lines of personal insights, breaking recruiter reading ergonomics and failing standard ATS parse budgets.
HONEST POST-MORTEM: IDENTIFYING BOTTLENECKS BEFORE USERS ENCOUNTER THEM ritvikchunamari.github.io
04 • The Iteration Loop Engineering Solutions
SLIDE 05 / 07

Engineering the Fixes: Optimization as Craft

Fixing these bottlenecks required treating performance not as a late cleanup task, but as a primary design constraint that directly sharpened the visual language.

Fix 01 • Performance
Zero-Render DOM Scroll
Eliminated 3D perspective transforms and replaced React state scroll hooks with direct CSS custom property updates managed inside a single requestAnimationFrame loop. Achieved a locked 120fps scroll experience.
◆ 120 FPS Locked • Zero Layout Thrashing
Fix 02 • Touch UX
Touch-Aware Soft Fade
Implemented pointer media queries like @media (hover: none) and dynamic touch listeners. The cursor and particle physics smoothly fade to 0 opacity the moment a touch gesture starts, restoring native mobile scrolling.
◆ Frictionless Mobile Ergonomics
Fix 03 • Typography & PDF
Fluid Math & 2-Page Budget
Calibrated fluid clamp() typography formulas ensuring "Ritvik" and "Chunamari" occupy 100% of the allocated mobile width with zero overflow. Rebalanced resume print geometry into an exact 2-page vector PDF.
◆ Perfect Edge-to-Edge Typography

05 • Retrospective Core Takeaways
SLIDE 06 / 07

What I Learned: Beyond the Mockup

Three fundamental truths about digital product design that only revealed themselves through hands-on code and production deployment.

Takeaway 01
Performance IS User Experience
A beautiful design that stutters or drops frames immediately destroys user trust. Fluidity, input responsiveness, and latency communicate high craftsmanship far more deeply than decorative graphics ever could.
◆ 60/120fps is a Design Requirement
Takeaway 02
Restraint Over Spectacle
The initial urge when building an interactive portfolio is to cram in every animation, particle, and 3D angle. True design discipline lies in removing decorative noise so the case studies and typography take center stage.
◆ Subtlety Elevates Content
Takeaway 03
The Power of the Hybrid Mindset
Designing with code creates an intuition for browser execution—reflows, repaint cycles, and memory management. When you understand how the browser thinks, your UI designs become inherently cleaner and more feasible.
◆ Designer-Engineer Symbiosis
